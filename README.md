# nordea_assignment
This project has code that can convert text into either XML formatted data or comma separated (CSV) data. The text is to be parsed, broken into sentences and words and the words have to be sorted.
Command to run:
1) Clone the code from GitHub 
2) Please keep .in file in /repository/input    .....Already given test file are there
3) Please do maven clean 
4) Please do maven install ...after install is done automatically output files .csv, .xml in /repository/output.....PLEASE REFRESH THE PROJECT USING MAVEN REFRESH...you will see all output files.
